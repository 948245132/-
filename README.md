# 自我心理治疗—起点
## 前言
这里我打算用尼布尔的祈祷文作为开头：

>请赐予我平静，去接受我无法改变的；
>
>请给予我勇气，去改变我能改变的；
>
>请赐予我智慧，分辨这两者的区别。

## 为何要进行心理治愈

时代奔流不息，科技的光影日新月异，但是不管过去多少年，“我是谁，我从哪里来，我将向何处去”这一哈姆雷特式的命题依旧无时无刻不在困扰着人们。回望华夏五千年的历史，先贤们为解决这一命题也提出了很多设想：命理，道教，儒教等等，这些概念和思想的出现与兴起无不是对这份古老追问的回应。信仰神明，或将命运寄托于星辰，在某种程度上，亦是古人为寻觅心灵慰藉与生命意义所做的努力。

时至今日，人们很难诚心诚意地信仰上帝，很难背负起国家重任，也很难融入一个源远流长的大家族，如此也就找不到人生的意义；这也造成了，在物质丰沛的表象下，意义的空洞却愈发凸显。

我也是如此，未能在时代的洪流中幸免于难，虽然听过了疫情的浪潮，但是之后不幸的是还是失业了，回到家乡再次不停的投简历，但是依旧难觅一份契合的工作，此刻我才惊觉，十二年的寒窗苦读，加上三年的工作经验，并没有让我的长衫变得更加值钱，我未能如愿踏入那象征成功的“偏房”，却似乎也失去了与“短衫客”们围坐共饮的坦然。我唯一拿的出手的“茴”字的四种写法，反而成了我被嘲笑的源泉。

当下的我，与鲁迅笔下的孔乙己何其相似。“哀其不幸，怒其不争”，昔日语文课堂上的评语言犹在耳，但是当自己成为“曲中人”的时候，才发现改变是如此的困难，内心的混乱与不安，让我每一步都踏在不安的薄冰上，举步维艰。

然而，困顿之中，一丝微光未曾泯灭。我决定开始阅读关于心理的书籍，试图在那探索人类内在世界的智慧中，寻求一丝对现状的解读，一缕对心灵的慰藉，或许，同时也希望可以从中找到救赎。这并非逃避，而是希望在理解自我与世界的迷宫中，重新绘制一张属于自己的地图。
